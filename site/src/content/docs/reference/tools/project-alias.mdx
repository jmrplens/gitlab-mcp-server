A project alias is a short name an administrator gives a project, which git clones the project by. These actions list the aliases, read one, create one and delete one, and are administrator actions.

## Sample questions

- "List the project aliases"
- "Create the alias gitlab for project 42"
- "Delete the alias legacy-api"

## How to call it

- **Dynamic**, the default surface: call `gitlab_execute_action` with `action` set to the action's ID, such as `project_alias.create`, and its parameters in `params`. `gitlab_find_action` finds an ID from a description of the task.
- **Meta** (`GITLAB_MCP_TOOL_SURFACE=meta`): call `gitlab_project_alias` with `action` set to the action's name, such as `create`, and its parameters in `params`.
- **Individual** (`GITLAB_MCP_TOOL_SURFACE=individual`): call the action's own tool, such as `gitlab_create_project_alias`, with its parameters as the arguments.

## Availability

How many of these actions an instance serves at each tier, out of a total of 4:

- **Free**: 0
- **Premium**: 4
- **Ultimate**: 4

Listed only for a token that carries `admin_mode`: the server removes the group from every surface for a token whose scopes it knows and that lacks it.

Read-only actions: 2 of 4, the ones a deployment in read-only mode keeps. A token with `read_api` and not `api` is served 2 of the 4.

### `project_alias.create`

> Create a project alias mapping a unique name to a numeric project_id (admin-only). Returns: the created alias with id, project_id, and name. See also: [`project_alias.list`](#project_aliaslist), [`project_alias.get`](#project_aliasget), [`project_alias.delete`](#project_aliasdelete).

- **Meta-tool**: `gitlab_project_alias`, action `create`
- **Individual tool**: `gitlab_create_project_alias`
- **Tier**: Premium
- **Classic or OAuth token**: `api`; this server lists the group only to a token that also carries `admin_mode`
- **Fine-grained token**: Alias: Create at instance ([permissions page](/gitlab-mcp-server/reference/fine-grained-permissions/#project_alias))
- **Behavior**: writes, not idempotent

| Parameter    | Type      | Mandatory | Description                     |
| ------------ | --------- | --------- | ------------------------------- |
| `name`       | `string`  | yes       | The alias name to create        |
| `project_id` | `integer` | yes       | The numeric project ID to alias |

The CI/CD Catalog lists the projects that publish reusable CI/CD components, the building blocks a pipeline pulls in with `include:component`. `ci_catalog.list` searches and sorts the published resources, and `ci_catalog.get` reads one, with the components and inputs of its latest version and its recent versions. The Catalog is served by GitLab's GraphQL API, and both actions only read.

## Sample questions

- "Search the CI/CD Catalog for Docker build components"
- "Which versions of the auto-deploy component are published?"
- "List the catalog resources sorted by stars"

## How to call it

- **Dynamic**, the default surface: call `gitlab_execute_action` with `action` set to the action's ID, such as `ci_catalog.get`, and its parameters in `params`. `gitlab_find_action` finds an ID from a description of the task.
- **Meta** (`GITLAB_MCP_TOOL_SURFACE=meta`): call `gitlab_ci_catalog` with `action` set to the action's name, such as `get`, and its parameters in `params`.
- **Individual** (`GITLAB_MCP_TOOL_SURFACE=individual`): call the action's own tool, such as `gitlab_get_catalog_resource`, with its parameters as the arguments.

### `ci_catalog.get`

> Get a single CI/CD Catalog resource by GID or full path. Returns: the resource with description, the latest version's README as Markdown and as HTML, latest-version components with their 30-day usage and their typed inputs (default, options, regex and conditional rules), the last ten versions with author and commit, star count, starrers path, and web path. See also: [`ci_catalog.list`](#ci_cataloglist), [`template.lint`](/gitlab-mcp-server/reference/tools/template/#templatelint), [`project.get`](/gitlab-mcp-server/reference/tools/project/#projectget).

- **Meta-tool**: `gitlab_ci_catalog`, action `get`
- **Individual tool**: `gitlab_get_catalog_resource`
- **Tier**: Free
- **Behavior**: read-only, idempotent

| Parameter   | Type     | Mandatory | Description                                                                                                                                |
| ----------- | -------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `full_path` | `string` | no        | Full path of the project hosting the resource (e.g. my-group/my-components). Give exactly one of id or full_path. Sending both is refused. |
| `id`        | `string` | no        | Catalog resource GID (e.g. `gid://gitlab/Ci::CatalogResource/1`). Give exactly one of id or full_path. Sending both is refused.            |

### `ci_catalog.list`

> List published CI/CD Catalog resources (component projects) with optional search, scope, and sort. Returns: catalog resources with id, name, full path, description, icon, latest version and release date, star count, starrers path, 30-day usage count, archived flag, topics, verification and visibility levels, web path, and keyset pagination metadata. See also: [`ci_catalog.get`](#ci_catalogget), [`template.lint`](/gitlab-mcp-server/reference/tools/template/#templatelint), [`pipeline.create`](/gitlab-mcp-server/reference/tools/pipeline/#pipelinecreate).

- **Meta-tool**: `gitlab_ci_catalog`, action `list`
- **Individual tool**: `gitlab_list_catalog_resources`
- **Tier**: Free
- **Behavior**: read-only, idempotent

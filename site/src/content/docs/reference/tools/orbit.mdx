Orbit is GitLab.com's experimental knowledge graph of code and project data. Its fifteen actions are served only to a session connected to GitLab.com at Premium or Ultimate, and all of them read: `orbit.status` checks the service, `orbit.schema` describes the graph, `orbit.dsl` serves the query language, `orbit.query` runs a query and `orbit.named_query` one of GitLab's named queries, `orbit.grep` searches a group or project, `orbit.context` resolves one reference to its summary, `orbit.graph_status` reports the indexing of a namespace or a project, and `orbit.tools`, `orbit.command_list`, `orbit.response_format`, `orbit.query_templates` and the three skill reads describe what Orbit serves. GitLab.com serves a group's index and its queries only under the top-level group's Orbit access. The [Orbit page](/gitlab-mcp-server/tools/orbit/) explains the workflow.

## Sample questions

- "Is Orbit available for this GitLab.com token?"
- "Show the knowledge graph schema"
- "Has gitlab-org/gitlab finished indexing?"
- "Search gitlab-org/gitlab for merge requests about rate limits"
- "Summarize this merge request with its changed files and failed jobs"
- "Run the recent_merges query template"

## How to call it

- **Dynamic**, the default surface: call `gitlab_execute_action` with `action` set to the action's ID, such as `orbit.command_list`, and its parameters in `params`. `gitlab_find_action` finds an ID from a description of the task.
- **Meta** (`GITLAB_MCP_TOOL_SURFACE=meta`): call `gitlab_orbit` with `action` set to the action's name, such as `command_list`, and its parameters in `params`.
- **Individual** (`GITLAB_MCP_TOOL_SURFACE=individual`): call the action's own tool, such as `gitlab_orbit_command_list`, with its parameters as the arguments.

## Availability

How many of these actions an instance serves at each tier, out of a total of 15:

- **Free**: 0
- **Premium**: 0 on a self-managed instance, 15 on GitLab.com
- **Ultimate**: 0 on a self-managed instance, 15 on GitLab.com

Read-only actions: 15 of 15, the ones a deployment in read-only mode keeps. A token with `read_api` and not `api` is served 15 of the 15.

### `orbit.command_list`

### `orbit.context`

> Resolve one reference to a work item, merge request, job, pipeline, branch or commit through GitLab Orbit (Knowledge Graph) and read its summary, discussions, changed files and failed jobs' logs, and with expand the graph neighborhood of one of the first three, one billable query. A reference it cannot resolve is found false with the reason, not_found also for an object the user or token may not read: a fine-grained token needs, beside read_orbit, permission to read on the object's own project or group. Summary parts it may not read are left out, and a failed expansion carries its reason.

- **Meta-tool**: `gitlab_orbit`, action `context`
- **Individual tool**: `gitlab_orbit_context`
- **Tier**: Premium, GitLab.com only
- **Classic or OAuth token**: `read_api` (or `api`)
- **Fine-grained token**: Orbit: Read at user ([permissions page](/gitlab-mcp-server/reference/fine-grained-permissions/#orbit))
- **Behavior**: read-only, idempotent

| Parameter         | Type       | Mandatory | Description                                                                                                                                                                                                                                                                                    |
| ----------------- | ---------- | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `tokens`          | `string[]` | yes       | Exactly one reference to a GitLab object: Type\[id\] (WorkItem\[1\], Job\[2\]), a GID, an instance URL, path!iid (merge request), path\#iid (work item), path&iid (epic) or path@ref (branch or commit). orbit.grep returns the token of a work item, merge request, commit or branch it finds |
| `expand`          | `boolean`  | no        | Attach the graph neighborhood of a work item, merge request or job, which GitLab reads with one graph query billed like orbit.query; false reads the summary alone                                                                                                                             |
| `response_format` | `string`   | no        | Response format: raw (structured JSON, the default) or llm (compact text). json is read as raw.                                                                                                                                                                                                |

| ----------------- | ---------- | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| `full_path`       | `string`   | no        | Full path of the group or project to search. Give exactly one of namespace_id, project_id and full_path                                                                                                                                                                                                                                                                                                                            |

GitLab answers 20 when omitted                                                                                                                                                                                                                                                                                                                                                                    |

Give exactly one of namespace_id, project_id and full_path                                                                                                                                                                                                                                                                                                                                            |
| `response_format` | `string`   | no        | Response format: raw (structured JSON, the default) or llm (compact text). json is read as raw.                                                                                                                                                                                                                                                                                                                                    |
| `scopes`          | `string[]` | no        | What to search: work_items, merge_requests, blobs, commits, notes, milestones, users, projects, groups, branches, an alias (mr, issue, code, comment, branch) or a node name (MergeRequest, File). ### `orbit.query`

> Execute a read-only GitLab Orbit (Knowledge Graph) query in GQL, the language orbit.dsl describes, naming what orbit.schema lists. A query is one MATCH ... RETURN statement sent as text, with at least one node bounded by its id or a literal property, and a refused query is corrected from the message GitLab answers with.

- **Meta-tool**: `gitlab_orbit`, action `query`
- **Individual tool**: `gitlab_orbit_query`
- **Tier**: Premium, GitLab.com only
- **Classic or OAuth token**: `read_api` (or `api`)
- **Fine-grained token**: Orbit: Read at user ([permissions page](/gitlab-mcp-server/reference/fine-grained-permissions/#orbit))
- **Behavior**: read-only, idempotent

| Parameter         | Type     | Mandatory | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ----------------- | -------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `query`           | `string` | yes       | Orbit query as GQL text, the read-only openCypher 9 based language GitLab.com compiles (orbit.dsl describes it). One statement: MATCH pattern \[WHERE predicates\] RETURN projections \[ORDER BY key \[ASC or DESC\]\] \[SKIP n\] \[LIMIT n\]. Label every node and anchor at least one by its id or a literal property, as in MATCH (p:Project \{full_path: 'gitlab-org/gitlab'\}) RETURN p.id, p.full_path LIMIT 1; LIMIT is not a filter. A relationship type follows a colon, -\[:IN_PROJECT\]-\>, several types are joined by \|, -\[:IN_PROJECT\|CONTAINS\*1..3\]-\>, and a repeat is bounded, \*1..3 at most. A shortest path, MATCH path = ANY SHORTEST (mr:MergeRequest \{id: 1\})-\[:IN_PROJECT\*1..3\]-\>(p:Project \{id: 2\}) RETURN path, labels and anchors both ends and names its relationship types: GitLab.com refuses the wildcard -\[\*1..3\]-\> there. WHERE takes AND and NOT, never OR. count, sum, avg, min and max aggregate, and every other RETURN item groups; alias an aggregate and sort by the alias: RETURN p, count(mr) AS mr_count ORDER BY mr_count DESC. SKIP takes 0 to 10000 and LIMIT 1 to 1000. orbit.schema lists the entities, properties and relationship types a query names. The JSON query DSL GitLab.com read before is gone. GitLab refuses a query it cannot compile with a message naming the fault. |
| `response_format` | `string` | no        | Response format: raw (structured JSON, the default here), llm (compact text) or gql (the result as a graph pattern table). json is read as raw.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |

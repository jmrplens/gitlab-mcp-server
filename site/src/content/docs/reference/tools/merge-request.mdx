The life of a merge request: create, read, list (in a project, a group or everywhere), update, merge, cancel an automatic merge, rebase and delete; approve and unapprove it, read its approval configuration and reset its approvals; its commits, context commits, pipelines (list them or start one), participants, reviewers, related issues and the issues it closes; subscriptions, to-do items, time estimates and spent time; award emoji on it and its notes; and the label, milestone and state events of its history.

Approval rules, approval state, project and group approval settings, and merge request dependencies are served from Premium. Comments, discussions, diffs and draft notes are on [Merge request review](/gitlab-mcp-server/reference/tools/mr-review/).

## Sample questions

- "Show the open merge requests of project 42"
- "Create a merge request from feature-login to main"
- "Merge merge request !15 once its pipeline passes"
- "Which merge requests are waiting for my review?"

## How to call it

- **Dynamic**, the default surface: call `gitlab_execute_action` with `action` set to the action's ID, such as `merge_request.approval_config`, and its parameters in `params`. `gitlab_find_action` finds an ID from a description of the task.
- **Meta** (`GITLAB_MCP_TOOL_SURFACE=meta`): call `gitlab_merge_request` with `action` set to the action's name, such as `approval_config`, and its parameters in `params`.
- **Individual** (`GITLAB_MCP_TOOL_SURFACE=individual`): call the action's own tool, such as `gitlab_mr_approval_config`, with its parameters as the arguments.

- **Meta-tool**: `gitlab_merge_request`, action `related_issues`
- **Individual tool**: `gitlab_mr_related_issues`
- **Tier**: Free
- **Behavior**: read-only, idempotent

| Parameter           | Type                     | Mandatory | Description                                                                                                                                       |
| ------------------- | ------------------------ | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `merge_request_iid` | `integer`                | yes       | Merge request IID (project-scoped, not 'merge_request_id')                                                                                        |
| `project_id`        | `string/integer`         | yes       | Project ID or URL-encoded path                                                                                                                    |
| `order_by`          | `string`                 | no        | Column to order results by (e.g. created_at)                                                                                                      |
| `page`              | `integer`                | no        | Page number to fetch, 1-based. Defaults to 1. Use the next_page field from the previous response to paginate forward.                             |
| `page_token`        | `string`                 | no        | Keyset pagination cursor: record id at which to fetch the next page, taken from the previous keyset response. Only used when pagination='keyset'. |
| `pagination`        | `string`                 | no        | Pagination method: 'keyset' for keyset-based pagination on large ordered result sets, or 'offset' (the default). Keyset avoids deep-offset cost.  |
| `per_page`          | `integer`                | no        | Items per page. Defaults to 20, minimum 1, maximum 100. Use 100 to minimize round trips when the result set is large.                             |
| `sort`              | `string` (`asc`, `desc`) | no        | Sort direction (asc, desc)                                                                                                                        |

- **Tier**: Free
- **Behavior**: writes, idempotent

| Parameter              | Type                         | Mandatory | Description                                                        |
| ---------------------- | ---------------------------- | --------- | ------------------------------------------------------------------ |
| `merge_request_iid`    | `integer`                    | yes       | Merge request IID (project-scoped, not 'merge_request_id')         |
| `project_id`           | `string/integer`             | yes       | Project ID or URL-encoded path                                     |
| `add_labels`           | `string[]`                   | no        | Label names to add without removing existing                       |

The whole life of an issue: create, read, list (in a project, a group or everywhere the user can see), update (closing and reopening included), reorder, move to another project and delete; subscriptions and to-do items; its notes and threaded discussions; links to other issues; time estimates and spent time; its participants and the merge requests related to it or closing it; award emoji on the issue and its notes; and the label, milestone and state events of its history. Issue statistics count issues by state.

Work items, the GraphQL model behind issues, epics and tasks, are actions here too, with their types and saved views. Iteration and weight events, and listing a project's or a group's iterations, are served from Premium.

On GitLab 19.4, `issue.work_item_saved_view_create` and `issue.work_item_saved_view_subscribe` made with a token nearly always answer 500: subscribing a user to a view locks the user's row while GitLab's sign-in tracking has left unsaved changes on it, which GitLab refuses. The create meets it after the view is saved, so the view exists and its creator is not subscribed; the error says so and names `issue.work_item_saved_view_list`, since creating the view again adds a duplicate. The subscribe fails before recording anything. The other saved view actions are not affected.

## Sample questions

- "List the open issues of project 42"
- "Create an issue about the login bug and assign it to me"
- "Close issue 10 with a comment"
- "How much time has been spent on issue 7?"

## How to call it

- **Dynamic**, the default surface: call `gitlab_execute_action` with `action` set to the action's ID, such as `issue.create`, and its parameters in `params`. `gitlab_find_action` finds an ID from a description of the task.
- **Meta** (`GITLAB_MCP_TOOL_SURFACE=meta`): call `gitlab_issue` with `action` set to the action's name, such as `create`, and its parameters in `params`.
- **Individual** (`GITLAB_MCP_TOOL_SURFACE=individual`): call the action's own tool, such as `gitlab_issue_create`, with its parameters as the arguments.

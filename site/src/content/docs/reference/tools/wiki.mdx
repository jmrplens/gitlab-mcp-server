A project's wiki: list its pages, read one, create, update and delete one, and upload a file attachment that a page can reference. Group wikis are actions of [Groups](/gitlab-mcp-server/reference/tools/group/), served from Premium.

## Sample questions

- "List the wiki pages of project 42"
- "Show the Home wiki page"
- "Create a wiki page with the release checklist"

## How to call it

- **Dynamic**, the default surface: call `gitlab_execute_action` with `action` set to the action's ID, such as `wiki.create`, and its parameters in `params`. `gitlab_find_action` finds an ID from a description of the task.
- **Meta** (`GITLAB_MCP_TOOL_SURFACE=meta`): call `gitlab_wiki` with `action` set to the action's name, such as `create`, and its parameters in `params`.
- **Individual** (`GITLAB_MCP_TOOL_SURFACE=individual`): call the action's own tool, such as `gitlab_wiki_create`, with its parameters as the arguments.

## Availability

Every tier serves the whole group, on self-managed instances and on GitLab.com alike.

Read-only actions: 2 of 6, the ones a deployment in read-only mode keeps.

### `wiki.create`

> Create a new wiki page. Returns: the created page with title, slug, format, content, and encoding. See also: [`wiki.get`](#wikiget), [`wiki.update`](#wikiupdate), [`wiki.list`](#wikilist).

- **Meta-tool**: `gitlab_wiki`, action `create`
- **Individual tool**: `gitlab_wiki_create`
- **Tier**: Free
- **Behavior**: writes, not idempotent

| Parameter    | Type                                             | Mandatory | Description                                                 |
| ------------ | ------------------------------------------------ | --------- | ----------------------------------------------------------- |
| `content`    | `string`                                         | yes       | Content of the wiki page (Markdown, RDoc, AsciiDoc, or Org) |
| `project_id` | `string/integer`                                 | yes       | Project ID or URL-encoded path                              |
| `title`      | `string`                                         | yes       | Title of the wiki page                                      |
| `format`     | `string` (`markdown`, `rdoc`, `asciidoc`, `org`) | no        | Content format: markdown (default), rdoc, asciidoc, or org  |

### `wiki.delete`

> Delete a wiki page permanently. Returns: a success confirmation for the removed page. See also: [`wiki.get`](#wikiget), [`wiki.list`](#wikilist).

- **Meta-tool**: `gitlab_wiki`, action `delete`
- **Individual tool**: `gitlab_wiki_delete`
- **Tier**: Free
- **Behavior**: writes, destructive (needs confirmation), idempotent

| Parameter    | Type             | Mandatory | Description                                 |
| ------------ | ---------------- | --------- | ------------------------------------------- |
| `project_id` | `string/integer` | yes       | Project ID or URL-encoded path              |
| `slug`       | `string`         | yes       | URL-encoded slug of the wiki page to delete |

### `wiki.get`

> Get a single wiki page by slug. Returns: the page title, slug, format, content, and encoding. See also: [`wiki.list`](#wikilist), [`wiki.update`](#wikiupdate), [`wiki.delete`](#wikidelete).

- **Meta-tool**: `gitlab_wiki`, action `get`
- **Individual tool**: `gitlab_wiki_get`
- **Tier**: Free
- **Behavior**: read-only, idempotent

| Parameter     | Type             | Mandatory | Description                                           |
| ------------- | ---------------- | --------- | ----------------------------------------------------- |
| `project_id`  | `string/integer` | yes       | Project ID or URL-encoded path                        |
| `slug`        | `string`         | yes       | URL-encoded slug of the wiki page (e.g. 'my-page')    |
| `render_html` | `boolean`        | no        | Return HTML-rendered content instead of raw format    |
| `version`     | `string`         | no        | Wiki page version SHA to retrieve a specific revision |

### `wiki.list`

> List a project's wiki pages. Returns: each page's title, slug, and format (plus content when with_content is set), with hints to read or create pages. See also: [`wiki.get`](#wikiget), [`wiki.create`](#wikicreate).

- **Meta-tool**: `gitlab_wiki`, action `list`
- **Individual tool**: `gitlab_wiki_list`
- **Tier**: Free
- **Behavior**: read-only, idempotent

| Parameter      | Type             | Mandatory | Description                          |
| -------------- | ---------------- | --------- | ------------------------------------ |
| `project_id`   | `string/integer` | yes       | Project ID or URL-encoded path       |

### `wiki.upload_attachment`

> Upload an attachment to the project wiki repository. Returns: the attachment file name, file path, branch, URL, and ready-to-paste Markdown link. See also: [`wiki.get`](#wikiget), [`wiki.update`](#wikiupdate).

- **Meta-tool**: `gitlab_wiki`, action `upload_attachment`
- **Individual tool**: `gitlab_wiki_upload_attachment`
- **Tier**: Free
- **Behavior**: writes, not idempotent

| Parameter        | Type             | Mandatory | Description                                                               |
| ---------------- | ---------------- | --------- | ------------------------------------------------------------------------- |
| `filename`       | `string`         | yes       | Name of the file to upload (e.g. diagram.png)                             |
| `project_id`     | `string/integer` | yes       | Project ID or URL-encoded path                                            |
| `branch`         | `string`         | no        | Branch to upload the attachment to                                        |
| `content_base64` | `string`         | no        | Base64-encoded file content. Provide either content_base64 or file_path   |
| `file_path`      | `string`         | no        | Absolute path to a local file. Provide either file_path or content_base64 |

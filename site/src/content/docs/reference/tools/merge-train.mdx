A merge train queues merge requests into a target branch and tests each against the ones ahead of it before merging it. These actions list a project's merge trains or the train of one target branch, read the train entry of a merge request, and add a merge request to its train.

## Sample questions

- "What is on the merge train for main?"
- "Add merge request !15 to the merge train"
- "Where is merge request !15 in the train?"

## How to call it

- **Dynamic**, the default surface: call `gitlab_execute_action` with `action` set to the action's ID, such as `merge_train.add`, and its parameters in `params`. `gitlab_find_action` finds an ID from a description of the task.
- **Meta** (`GITLAB_MCP_TOOL_SURFACE=meta`): call `gitlab_merge_train` with `action` set to the action's name, such as `add`, and its parameters in `params`.
- **Individual** (`GITLAB_MCP_TOOL_SURFACE=individual`): call the action's own tool, such as `gitlab_add_merge_request_to_merge_train`, with its parameters as the arguments.

### `merge_train.add`

> Add a merge request to a merge train. Returns: the resulting merge train entries with the merge request, user, pipeline, target branch, status, and duration. See also: [`merge_train.get`](#merge_trainget), [`merge_train.list_branch`](#merge_trainlist_branch), [`merge_train.list_project`](#merge_trainlist_project).

- **Meta-tool**: `gitlab_merge_train`, action `add`
- **Individual tool**: `gitlab_add_merge_request_to_merge_train`
- **Tier**: Premium
- **Behavior**: writes, not idempotent

| Parameter                | Type             | Mandatory | Description                                                                        |
| ------------------------ | ---------------- | --------- | ---------------------------------------------------------------------------------- |
| `merge_request_iid`      | `integer`        | yes       | Merge request internal ID                                                          |
| `project_id`             | `string/integer` | yes       | Project ID or URL-encoded path                                                     |
| `auto_merge`             | `boolean`        | no        | Enable auto-merge when pipeline succeeds                                           |
| `sha`                    | `string`         | no        | Head SHA of the merge request to verify                                            |
| `squash`                 | `boolean`        | no        | Squash commits when merging                                                        |
| `when_pipeline_succeeds` | `boolean`        | no        | Deprecated in 17.11. Use auto_merge instead. Merge only when the pipeline succeeds |

Geo replicates a GitLab instance to other sites. These actions manage the sites (list, read, create, edit and delete), repair a site's OAuth application, and read the replication status of one site or of all of them. They are administrator actions.

## Sample questions

- "List the Geo sites"
- "What is the replication status of Geo site 2?"
- "Repair the OAuth application of the secondary site"

## How to call it

- **Dynamic**, the default surface: call `gitlab_execute_action` with `action` set to the action's ID, such as `geo.create`, and its parameters in `params`. `gitlab_find_action` finds an ID from a description of the task.
- **Meta** (`GITLAB_MCP_TOOL_SURFACE=meta`): call `gitlab_geo` with `action` set to the action's name, such as `create`, and its parameters in `params`.
- **Individual** (`GITLAB_MCP_TOOL_SURFACE=individual`): call the action's own tool, such as `gitlab_create_geo_site`, with its parameters as the arguments.

## Availability

How many of these actions an instance serves at each tier, out of a total of 8:

- **Free**: 0
- **Premium**: 8
- **Ultimate**: 8

Listed only for a token that carries `admin_mode`: the server removes the group from every surface for a token whose scopes it knows and that lacks it.

Read-only actions: 4 of 8, the ones a deployment in read-only mode keeps. A token with `read_api` and not `api` is served 4 of the 8.

### `geo.create`

> Create a new Geo site. Returns: the site with id, name, url, primary/enabled flags, capacities, selective-sync settings, and navigation links. See also: [`geo.list`](#geolist), [`geo.get`](#geoget), [`geo.edit`](#geoedit).

- **Meta-tool**: `gitlab_geo`, action `create`
- **Individual tool**: `gitlab_create_geo_site`
- **Tier**: Premium
- **Classic or OAuth token**: `api`; this server lists the group only to a token that also carries `admin_mode`
- **Fine-grained token**: Geo Site: Create at instance ([permissions page](/gitlab-mcp-server/reference/fine-grained-permissions/#geo))
- **Behavior**: writes, not idempotent

| Parameter                             | Type        | Mandatory | Description                                                 |
| ------------------------------------- | ----------- | --------- | ----------------------------------------------------------- |
| `container_repositories_max_capacity` | `integer`   | no        | Max number of concurrent container repository syncs         |
| `enabled`                             | `boolean`   | no        | Whether the site is enabled                                 |
| `files_max_capacity`                  | `integer`   | no        | Max number of LFS/attachment backfill downloads             |
| `internal_url`                        | `string`    | no        | Internal URL of the Geo site                                |
| `minimum_reverification_interval`     | `integer`   | no        | Minimum interval (days) before re-verification              |
| `name`                                | `string`    | no        | Unique name of the Geo site                                 |
| `primary`                             | `boolean`   | no        | Whether this is a primary site                              |
| `repos_max_capacity`                  | `integer`   | no        | Max number of concurrent repository backfill syncs          |
| `selective_sync_namespace_ids`        | `integer[]` | no        | Namespace IDs to sync (when selective_sync_type=namespaces) |
| `selective_sync_shards`               | `string[]`  | no        | Storage shards to sync (when selective_sync_type=shards)    |
| `selective_sync_type`                 | `string`    | no        | Selective sync type: namespaces or shards                   |
| `sync_object_storage`                 | `boolean`   | no        | Whether to sync object-stored data                          |
| `url`                                 | `string`    | no        | External URL of the Geo site                                |
| `verification_max_capacity`           | `integer`   | no        | Max number of concurrent verification jobs                  |

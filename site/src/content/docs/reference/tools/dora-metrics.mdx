GitLab computes the four DORA metrics from a project's deployments: deployment frequency, lead time for changes, time to restore service and change failure rate. `dora_metrics.project` and `dora_metrics.group` read one of them over a date range, by day, by month or as one figure, optionally for chosen environment tiers.

## Sample questions

- "What is the deployment frequency of project 42 this quarter?"
- "Show the monthly change failure rate of group platform"
- "How long did project 42 take to restore service in September?"

## How to call it

- **Dynamic**, the default surface: call `gitlab_execute_action` with `action` set to the action's ID, such as `dora_metrics.group`, and its parameters in `params`. `gitlab_find_action` finds an ID from a description of the task.
- **Meta** (`GITLAB_MCP_TOOL_SURFACE=meta`): call `gitlab_dora_metrics` with `action` set to the action's name, such as `group`, and its parameters in `params`.
- **Individual** (`GITLAB_MCP_TOOL_SURFACE=individual`): call the action's own tool, such as `gitlab_get_group_dora_metrics`, with its parameters as the arguments.

## Availability

How many of these actions an instance serves at each tier, out of a total of 2:

- **Free**: 0
- **Premium**: 0
- **Ultimate**: 2

Read-only actions: 2 of 2, the ones a deployment in read-only mode keeps. A token with `read_api` and not `api` is served 2 of the 2.

### `dora_metrics.group`

> Get the four DORA DevOps performance metrics aggregated across a group over a date window. Returns: one time series of date/value data points for the requested metric (deployment frequency, lead time for changes, time to restore service, or change failure rate), bucketed by interval. See also: [`dora_metrics.project`](#dora_metricsproject).

- **Meta-tool**: `gitlab_dora_metrics`, action `group`
- **Individual tool**: `gitlab_get_group_dora_metrics`
- **Tier**: Ultimate
- **Classic or OAuth token**: `read_api` (or `api`)
- **Fine-grained token**: Dora Metric: Read at group ([permissions page](/gitlab-mcp-server/reference/fine-grained-permissions/#dora_metrics))
- **Behavior**: read-only, idempotent

| Parameter           | Type                                                                                                         | Mandatory | Description                                                                                                 |
| ------------------- | ------------------------------------------------------------------------------------------------------------ | --------- | ----------------------------------------------------------------------------------------------------------- |
| `group_id`          | `string/integer`                                                                                             | yes       | Group ID or URL-encoded path                                                                                |
| `metric`            | `string` (`deployment_frequency`, `lead_time_for_changes`, `time_to_restore_service`, `change_failure_rate`) | yes       | DORA metric type: deployment_frequency, lead_time_for_changes, time_to_restore_service, change_failure_rate |
| `end_date`          | `string`                                                                                                     | no        | End date (YYYY-MM-DD)                                                                                       |
| `environment_tiers` | `string[]`                                                                                                   | no        | Filter by environment tiers (e.g. production, staging)                                                      |
| `interval`          | `string` (`daily`, `monthly`, `all`)                                                                         | no        | Aggregation interval: daily, monthly, all (default: daily)                                                  |
| `start_date`        | `string`                                                                                                     | no        | Start date (YYYY-MM-DD)                                                                                     |

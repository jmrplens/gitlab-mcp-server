Full-text search, one action per kind of result: code, merge requests, issues, commits, milestones, notes, projects, snippets, users and wiki pages. Each searches a project or a group when given one, and the whole instance otherwise. `search_type` asks for a search backend, `basic`, `advanced` or `zoekt`, and GitLab refuses one the instance has not enabled. Every action only reads.

## Sample questions

- "Search the code of group platform for parseConfig"
- "Find merge requests that mention the login bug"
- "Which issues mention timeout in project 42?"

## How to call it

- **Dynamic**, the default surface: call `gitlab_execute_action` with `action` set to the action's ID, such as `search.code`, and its parameters in `params`. `gitlab_find_action` finds an ID from a description of the task.
- **Meta** (`GITLAB_MCP_TOOL_SURFACE=meta`): call `gitlab_search` with `action` set to the action's name, such as `code`, and its parameters in `params`.
- **Individual** (`GITLAB_MCP_TOOL_SURFACE=individual`): call the action's own tool, such as `gitlab_search_code`, with its parameters as the arguments.

## Availability

Every tier serves the whole group, on self-managed instances and on GitLab.com alike.

Read-only actions: 10 of 10, the ones a deployment in read-only mode keeps. A token with `read_api` and not `api` is served 10 of the 10.

### `search.code`

> Search code blobs across global, group, or project scope. Returns: matching blobs with file path, basename, ref, starting line, the surrounding snippet, project ID, and pagination metadata. See also: [`search.projects`](#searchprojects), [`repository.file_get`](/gitlab-mcp-server/reference/tools/repository/#repositoryfile_get), [`repository.tree`](/gitlab-mcp-server/reference/tools/repository/#repositorytree).

- **Meta-tool**: `gitlab_search`, action `code`
- **Individual tool**: `gitlab_search_code`
- **Tier**: Free
- **Classic or OAuth token**: `read_api` (or `api`)
- **Fine-grained token**: one of: Global Search: Use at project **or** Global Search: Use at group **or** Global Search: Use at user ([permissions page](/gitlab-mcp-server/reference/fine-grained-permissions/#search))
- **Behavior**: read-only, idempotent

| Parameter     | Type                                    | Mandatory | Description                                                                                                                                                                                                                 |
| ------------- | --------------------------------------- | --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `query`       | `string`                                | yes       | Search query text (param 'query' not 'search')                                                                                                                                                                              |
| `group_id`    | `string`                                | no        | Group ID or URL-encoded path (optional)                                                                                                                                                                                     |
| `page`        | `integer`                               | no        | Page number to fetch, 1-based. Defaults to 1. Use the next_page field from the previous response to paginate forward.                                                                                                       |
| `per_page`    | `integer`                               | no        | Items per page. Defaults to 20, minimum 1, maximum 100. Use 100 to minimize round trips when the result set is large.                                                                                                       |
| `project_id`  | `string`                                | no        | Project ID or URL-encoded path (optional)                                                                                                                                                                                   |
| `ref`         | `string`                                | no        | Branch or tag name to search in (default: default branch)                                                                                                                                                                   |
| `search_type` | `string` (`basic`, `advanced`, `zoekt`) | no        | Search backend to request. Use 'basic' for GitLab's default search, 'advanced' for Elasticsearch/OpenSearch-backed search, or 'zoekt' for Zoekt-based search. The requested backend must be enabled on the GitLab instance. |

faq:
  - q: "¿Qué es GitLab MCP Server?"
    a: "GitLab MCP Server es un servidor [Model Context Protocol](https://modelcontextprotocol.io/), libre y de código abierto, que permite a los asistentes de IA interactuar con GitLab mediante lenguaje natural. Expone las APIs REST v4 y GraphQL de GitLab como herramientas MCP, de modo que un asistente puede revisar merge requests, diagnosticar pipelines, gestionar incidencias y redactar releases por ti. Se distribuye como un único binario de Go y se ejecuta localmente por stdio o de forma remota por HTTP."
  - q: "¿Con qué asistentes de IA funciona?"
    a: "Funciona con cualquier cliente compatible con MCP — incluidos VS Code con GitHub Copilot, Claude Desktop, Cursor y Claude Code, además de cualquier otro cliente que hable el Model Context Protocol por transporte stdio o HTTP. La configuración es un pequeño fragmento JSON por cliente."
  - q: "¿Es gratuito y de código abierto?"
    a: "Sí. GitLab MCP Server es gratuito y de código abierto bajo la licencia MIT, con todo el código fuente en GitHub. No existe una versión de pago del servidor; las funciones de GitLab Premium o Ultimate dependen únicamente de la licencia de tu propia instancia de GitLab, no del servidor MCP."
  - q: "¿Funciona con GitLab autoalojado y Community Edition?"
    a: "Sí. Funciona con GitLab.com y con instancias autoalojadas, y tanto con Community Edition como con Enterprise Edition. Apúntalo a cualquier URL de GitLab con un token de acceso personal. Las herramientas Premium y Ultimate se registran solo cuando la instancia conectada tiene la licencia correspondiente."

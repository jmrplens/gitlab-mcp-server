Gestión de ramas de un proyecto: leer y listar ramas, crear una a partir de una rama, una etiqueta o un commit, borrar una o todas las que ya están fusionadas, y proteger una rama con los niveles de acceso que pueden hacer push y merge, para después leer, actualizar o quitar esa protección.

`branch.rule_list` lee las reglas de rama que GitLab compone por GraphQL: para cada patrón de rama protegida, quién puede hacer push y merge, sus reglas de aprobación y sus comprobaciones de estado externas, en una sola respuesta donde la API REST necesita varias llamadas.

## Preguntas de ejemplo

- "Lista las ramas del proyecto 42"
- "Crea una rama llamada feature-login a partir de main"
- "Borra todas las ramas ya fusionadas en main"
- "¿Quién puede hacer push a main?"

## Cómo llamarlo

- **Dinámica**, la superficie predeterminada: llama a `gitlab_execute_action` con `action` igual al ID de la acción, como `branch.create`, y sus parámetros en `params`. `gitlab_find_action` encuentra un ID a partir de una descripción de la tarea.
- **Meta** (`GITLAB_MCP_TOOL_SURFACE=meta`): llama a `gitlab_branch` con `action` igual al nombre de la acción, como `create`, y sus parámetros en `params`.
- **Individual** (`GITLAB_MCP_TOOL_SURFACE=individual`): llama a la herramienta propia de la acción, como `gitlab_branch_create`, pasándole directamente sus parámetros.

## Disponibilidad

Todos los niveles sirven el grupo completo, tanto en instancias autogestionadas como en GitLab.com.

Acciones de solo lectura: 5 de 11, las que conserva un despliegue en modo de solo lectura.

### `branch.create`

> Create a branch from a source ref (branch, tag, or commit SHA). Returns: the created branch with its head commit object, protection and default flags, and web URL. - **Meta-herramienta**: `gitlab_branch`, acción `create`
- **Herramienta individual**: `gitlab_branch_create`
- **Nivel**: Free
- **Comportamiento**: escribe, no idempotente

| `branch_name` | `string`         | sí        | New branch name (param 'branch_name' not 'branch' or 'name') |

Un merge train pone en cola los merge requests hacia una rama de destino y prueba cada uno junto con los que van delante antes de fusionarlo. Estas acciones listan los merge trains de un proyecto o el tren de una rama de destino, leen la entrada de un merge request en el tren y añaden un merge request a su tren.

## Preguntas de ejemplo

- "¿Qué hay en el merge train de main?"
- "Añade el merge request !15 al merge train"
- "¿En qué posición del tren está el merge request !15?"

## Cómo llamarlo

- **Dinámica**, la superficie predeterminada: llama a `gitlab_execute_action` con `action` igual al ID de la acción, como `merge_train.add`, y sus parámetros en `params`. `gitlab_find_action` encuentra un ID a partir de una descripción de la tarea.
- **Meta** (`GITLAB_MCP_TOOL_SURFACE=meta`): llama a `gitlab_merge_train` con `action` igual al nombre de la acción, como `add`, y sus parámetros en `params`.
- **Individual** (`GITLAB_MCP_TOOL_SURFACE=individual`): llama a la herramienta propia de la acción, como `gitlab_add_merge_request_to_merge_train`, pasándole directamente sus parámetros.

## Disponibilidad

Cuántas de estas acciones sirve una instancia en cada nivel, de un total de 4:

- **Free**: 0
- **Premium**: 4
- **Ultimate**: 4

Acciones de solo lectura: 3 de 4, las que conserva un despliegue en modo de solo lectura.

### `merge_train.add`

> Add a merge request to a merge train. Returns: the resulting merge train entries with the merge request, user, pipeline, target branch, status, and duration. See also: [`merge_train.get`](#merge_trainget), [`merge_train.list_branch`](#merge_trainlist_branch), [`merge_train.list_project`](#merge_trainlist_project).

- **Meta-herramienta**: `gitlab_merge_train`, acción `add`
- **Herramienta individual**: `gitlab_add_merge_request_to_merge_train`
- **Nivel**: Premium
- **Comportamiento**: escribe, no idempotente

| Parámetro                | Tipo             | Requerido | Descripción                                                                        |
| ------------------------ | ---------------- | --------- | ---------------------------------------------------------------------------------- |
| `merge_request_iid`      | `integer`        | sí        | Merge request internal ID                                                          |
| `project_id`             | `string/integer` | sí        | Project ID or URL-encoded path                                                     |
| `auto_merge`             | `boolean`        | no        | Enable auto-merge when pipeline succeeds                                           |
| `sha`                    | `string`         | no        | Head SHA of the merge request to verify                                            |
| `squash`                 | `boolean`        | no        | Squash commits when merging                                                        |
| `when_pipeline_succeeds` | `boolean`        | no        | Deprecated in 17.11. Use auto_merge instead. Merge only when the pipeline succeeds |

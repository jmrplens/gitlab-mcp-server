Feature flags que lee la aplicación de un proyecto para activar una función de forma gradual: cada flag tiene estrategias (todos los usuarios, un porcentaje de usuarios o de despliegue, unos IDs de usuario o una lista de usuarios), limitadas a entornos. Estas acciones gestionan los flags y las listas de usuarios a las que puede apuntar una estrategia. Desactivar un flag conserva su historial; borrarlo no. Los feature flags propios de GitLab en la instancia son acciones de administración (consulta [Administración](/gitlab-mcp-server/reference/tools/admin/)).

## Preguntas de ejemplo

- "Lista los feature flags del proyecto 42"
- "Despliega new-checkout al 25 por ciento de los usuarios en production"
- "Crea una lista de usuarios para los probadores de la beta"

## Cómo llamarlo

- **Dinámica**, la superficie predeterminada: llama a `gitlab_execute_action` con `action` igual al ID de la acción, como `feature_flags.feature_flag_create`, y sus parámetros en `params`. `gitlab_find_action` encuentra un ID a partir de una descripción de la tarea.
- **Meta** (`GITLAB_MCP_TOOL_SURFACE=meta`): llama a `gitlab_feature_flags` con `action` igual al nombre de la acción, como `feature_flag_create`, y sus parámetros en `params`.
- **Individual** (`GITLAB_MCP_TOOL_SURFACE=individual`): llama a la herramienta propia de la acción, como `gitlab_feature_flag_create`, pasándole directamente sus parámetros.

## Disponibilidad

Todos los niveles sirven el grupo completo, tanto en instancias autogestionadas como en GitLab.com.

Acciones de solo lectura: 4 de 10, las que conserva un despliegue en modo de solo lectura.

### `feature_flags.feature_flag_create`

> Create a feature flag with optional activation strategies and scopes. Returns: the created flag with active state, version, scopes, and strategies. See also: [`feature_flags.feature_flag_get`](#feature_flagsfeature_flag_get), [`feature_flags.feature_flag_update`](#feature_flagsfeature_flag_update).

- **Meta-herramienta**: `gitlab_feature_flags`, acción `feature_flag_create`
- **Herramienta individual**: `gitlab_feature_flag_create`
- **Nivel**: Free
- **Comportamiento**: escribe, no idempotente

| Parámetro     | Tipo             | Requerido | Descripción                                                                                               |
| ------------- | ---------------- | --------- | --------------------------------------------------------------------------------------------------------- |
| `name`        | `string`         | sí        | Feature flag name                                                                                         |
| `project_id`  | `string/integer` | sí        | Project ID or path                                                                                        |
| `active`      | `boolean`        | no        | Whether the flag is active                                                                                |
| `description` | `string`         | no        | Feature flag description                                                                                  |
| `strategies`  | `object[]`       | no        | Activation strategies for the flag. Each has a name, optional parameters, and optional environment scopes |
| `version`     | `string`         | no        | Version of the feature flag (new_version_flag)                                                            |

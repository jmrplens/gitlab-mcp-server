Variables de CI/CD en los tres ámbitos en los que GitLab las guarda: un proyecto, un grupo y la instancia, cada uno con las mismas cinco operaciones. Una variable puede ser protegida, enmascarada o enmascarada y oculta, y las de proyecto y de grupo pueden limitarse a un entorno, así que una clave puede tener un valor distinto en cada entorno. Las variables de instancia necesitan un administrador, y borrar una variable no se puede deshacer.

## Preguntas de ejemplo

- "Lista las variables de CI/CD del proyecto 42"
- "Añade una variable enmascarada DEPLOY_TOKEN limitada a production"
- "¿Qué variables de grupo define el grupo platform?"

## Cómo llamarlo

- **Dinámica**, la superficie predeterminada: llama a `gitlab_execute_action` con `action` igual al ID de la acción, como `ci_variable.create`, y sus parámetros en `params`. `gitlab_find_action` encuentra un ID a partir de una descripción de la tarea.
- **Meta** (`GITLAB_MCP_TOOL_SURFACE=meta`): llama a `gitlab_ci_variable` con `action` igual al nombre de la acción, como `create`, y sus parámetros en `params`.
- **Individual** (`GITLAB_MCP_TOOL_SURFACE=individual`): llama a la herramienta propia de la acción, como `gitlab_ci_variable_create`, pasándole directamente sus parámetros.

## Disponibilidad

Todos los niveles sirven el grupo completo, tanto en instancias autogestionadas como en GitLab.com.

Acciones de solo lectura: 6 de 15, las que conserva un despliegue en modo de solo lectura.

### `ci_variable.create`

> Create a CI/CD variable in a project with type, environment scope, and protected/masked/raw/masked_and_hidden flags. Returns: the created variable's key, value (redacted when masked or hidden), type, flags, environment scope, and description. See also: [`ci_variable.list`](#ci_variablelist), [`ci_variable.get`](#ci_variableget), [`ci_variable.update`](#ci_variableupdate).

- **Meta-herramienta**: `gitlab_ci_variable`, acción `create`
- **Herramienta individual**: `gitlab_ci_variable_create`
- **Nivel**: Free
- **Comportamiento**: escribe, no idempotente

| Parámetro           | Tipo                         | Requerido | Descripción                            |
| ------------------- | ---------------------------- | --------- | -------------------------------------- |
| `key`               | `string`                     | sí        | Variable key name                      |
| `project_id`        | `string/integer`             | sí        | Project ID or URL-encoded path         |
| `value`             | `string`                     | sí        | Variable value                         |
| `description`       | `string`                     | no        | Variable description                   |
| `environment_scope` | `string`                     | no        | Environment scope (default: \*)        |
| `masked`            | `boolean`                    | no        | Mask variable value in job logs        |
| `masked_and_hidden` | `boolean`                    | no        | Mask and hide variable value           |
| `protected`         | `boolean`                    | no        | Only expose in protected branches/tags |
| `raw`               | `boolean`                    | no        | Treat variable value as raw string     |
| `variable_type`     | `string` (`env_var`, `file`) | no        | Variable type: env_var or file         |

Un grupo o un proyecto define un logro, y concedérselo a una persona crea un logro de usuario: un registro aparte, con su propio ID numérico, que se puede revocar, ocultar de un perfil, reordenar o borrar sin tocar el logro del que procede. Por eso estas acciones manejan dos identificadores: `achievement_id` nombra el logro y `user_achievement_id` nombra una concesión de él, que es lo que reciben `achievement.revoke` y las acciones `achievement.user_achievement_*`.

Revocar una concesión la conserva en el registro marcada como revocada, `achievement.user_achievement_delete` borra una concesión y `achievement.delete` elimina el logro con todas las concesiones hechas de él. Los logros están disponibles de forma general desde GitLab 19.3; en una instancia anterior un administrador tiene que activar antes el feature flag `achievements`.

## Preguntas de ejemplo

- "¿Qué logros define el grupo platform?"
- "Concede el logro First Contribution al usuario 42"
- "¿Quién tiene el logro First Contribution?"
- "Oculta esa concesión de mi perfil"

## Cómo llamarlo

- **Dinámica**, la superficie predeterminada: llama a `gitlab_execute_action` con `action` igual al ID de la acción, como `achievement.award`, y sus parámetros en `params`. `gitlab_find_action` encuentra un ID a partir de una descripción de la tarea.
- **Meta** (`GITLAB_MCP_TOOL_SURFACE=meta`): llama a `gitlab_achievement` con `action` igual al nombre de la acción, como `award`, y sus parámetros en `params`.
- **Individual** (`GITLAB_MCP_TOOL_SURFACE=individual`): llama a la herramienta propia de la acción, como `gitlab_achievement_award`, pasándole directamente sus parámetros.

## Disponibilidad

Todos los niveles sirven el grupo completo, tanto en instancias autogestionadas como en GitLab.com.

Acciones de solo lectura: 4 de 12, las que conserva un despliegue en modo de solo lectura.

### `achievement.award`

> Award an achievement to a user. Returns: the new award with its own id, achievement_id, user_id, awarded_by_user_id, award_message, priority, show_on_profile, and timestamps. See also: [`achievement.revoke`](#achievementrevoke), [`achievement.recipients`](#achievementrecipients), [`achievement.user_list`](#achievementuser_list).

- **Meta-herramienta**: `gitlab_achievement`, acción `award`
- **Herramienta individual**: `gitlab_achievement_award`
- **Nivel**: Free
- **Comportamiento**: escribe, no idempotente

| Parámetro        | Tipo      | Requerido | Descripción                                          |
| ---------------- | --------- | --------- | ---------------------------------------------------- |
| `achievement_id` | `integer` | sí        | Numeric ID of the achievement to hand out            |
| `user_id`        | `integer` | sí        | Numeric ID of the user receiving the achievement     |
| `award_message`  | `string`  | no        | Note shown alongside the award, up to 200 characters |

### `achievement.create`

> Define a new achievement in a group or project namespace. Creating one awards it to nobody. Returns: the created achievement with id, namespace_id, name, description, avatar_url, and timestamps. See also: [`achievement.award`](#achievementaward), [`achievement.list`](#achievementlist), [`achievement.update`](#achievementupdate).

- **Meta-herramienta**: `gitlab_achievement`, acción `create`
- **Herramienta individual**: `gitlab_achievement_create`
- **Nivel**: Free
- **Comportamiento**: escribe, no idempotente

| Parámetro               | Tipo      | Requerido | Descripción                                                                                                                                                                                                                                |
| ----------------------- | --------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `name`                  | `string`  | sí        | Display name of the achievement such as First Contribution                                                                                                                                                                                 |
| `namespace_id`          | `integer` | sí        | Numeric ID of the group or project namespace that will own the achievement                                                                                                                                                                 |
| `avatar_content_base64` | `string`  | no        | Base64-encoded avatar image bytes. Alternative to avatar_file_path. Only one of the two should be provided                                                                                                                                 |

| `avatar_file_path`      | `string`  | no        | Absolute path to a local image file the MCP server reads. Alternative to avatar_content_base64 for files too large to base64-encode. Only one of the two should be provided, and neither is available when the server is reached over HTTP |

| `description`           | `string`  | no        | Free-text explanation of what the achievement is awarded for                                                                                                                                                                               |

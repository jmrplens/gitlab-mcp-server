Geo replica una instancia de GitLab en otros sitios. Estas acciones gestionan los sitios (listar, leer, crear, editar y borrar), reparan la aplicación OAuth de un sitio y leen el estado de replicación de un sitio o de todos. Son acciones de administrador.

## Preguntas de ejemplo

- "Lista los sitios Geo"
- "¿Cuál es el estado de replicación del sitio Geo 2?"
- "Repara la aplicación OAuth del sitio secundario"

## Cómo llamarlo

- **Dinámica**, la superficie predeterminada: llama a `gitlab_execute_action` con `action` igual al ID de la acción, como `geo.create`, y sus parámetros en `params`. `gitlab_find_action` encuentra un ID a partir de una descripción de la tarea.
- **Meta** (`GITLAB_MCP_TOOL_SURFACE=meta`): llama a `gitlab_geo` con `action` igual al nombre de la acción, como `create`, y sus parámetros en `params`.
- **Individual** (`GITLAB_MCP_TOOL_SURFACE=individual`): llama a la herramienta propia de la acción, como `gitlab_create_geo_site`, pasándole directamente sus parámetros.

## Disponibilidad

Cuántas de estas acciones sirve una instancia en cada nivel, de un total de 8:

- **Free**: 0
- **Premium**: 8
- **Ultimate**: 8

Solo se lista para un token que tenga `admin_mode`: el servidor quita el grupo de todas las superficies a un token cuyos ámbitos conoce y que no lo tiene.

Acciones de solo lectura: 4 de 8, las que conserva un despliegue en modo de solo lectura. A un token con `read_api` y sin `api` se le sirven 4 de las 8.

## Acciones

La descripción de cada acción, y la de cada uno de sus parámetros, es el texto que sirve el servidor para ella en la superficie predeterminada, citado tal cual; por eso está en inglés. Las líneas de token dicen lo que exige GitLab 19.4.1 a un token para las peticiones que envía cada acción; en una instancia con Admin Mode activado, una acción que solo puede ejecutar un administrador necesita además `admin_mode`. Una acción destructiva solo se ejecuta una vez confirmada, salvo que `GITLAB_MCP_YOLO_MODE` (o `AUTOPILOT`) se salte ese paso: la superficie dinámica necesita `confirm: true` en `gitlab_execute_action`, y las otras dos aceptan un parámetro `confirm` o la pregunta del cliente ([Acciones destructivas](/gitlab-mcp-server/operations/security/#acciones-destructivas)).

### `geo.create`

> Create a new Geo site. Returns: the site with id, name, url, primary/enabled flags, capacities, selective-sync settings, and navigation links. See also: [`geo.list`](#geolist), [`geo.get`](#geoget), [`geo.edit`](#geoedit).

- **Meta-herramienta**: `gitlab_geo`, acción `create`
- **Herramienta individual**: `gitlab_create_geo_site`
- **Nivel**: Premium
- **Token clásico u OAuth**: `api`; este servidor solo lista el grupo a un token que lleve además `admin_mode`
- **Token de grano fino**: Geo Site: Create en instancia ([página de permisos](/gitlab-mcp-server/reference/fine-grained-permissions/#geo))
- **Comportamiento**: escribe, no idempotente

| Parámetro                             | Tipo        | Requerido | Descripción                                                 |
| ------------------------------------- | ----------- | --------- | ----------------------------------------------------------- |
| `container_repositories_max_capacity` | `integer`   | no        | Max number of concurrent container repository syncs         |
| `enabled`                             | `boolean`   | no        | Whether the site is enabled                                 |
| `files_max_capacity`                  | `integer`   | no        | Max number of LFS/attachment backfill downloads             |
| `internal_url`                        | `string`    | no        | Internal URL of the Geo site                                |
| `minimum_reverification_interval`     | `integer`   | no        | Minimum interval (days) before re-verification              |
| `name`                                | `string`    | no        | Unique name of the Geo site                                 |
| `primary`                             | `boolean`   | no        | Whether this is a primary site                              |
| `repos_max_capacity`                  | `integer`   | no        | Max number of concurrent repository backfill syncs          |
| `selective_sync_namespace_ids`        | `integer[]` | no        | Namespace IDs to sync (when selective_sync_type=namespaces) |
| `selective_sync_shards`               | `string[]`  | no        | Storage shards to sync (when selective_sync_type=shards)    |
| `selective_sync_type`                 | `string`    | no        | Selective sync type: namespaces or shards                   |
| `sync_object_storage`                 | `boolean`   | no        | Whether to sync object-stored data                          |
| `url`                                 | `string`    | no        | External URL of the Geo site                                |
| `verification_max_capacity`           | `integer`   | no        | Max number of concurrent verification jobs                  |

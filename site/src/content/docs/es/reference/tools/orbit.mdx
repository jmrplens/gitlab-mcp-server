Orbit es el grafo de conocimiento experimental de GitLab.com sobre el código y los datos de los proyectos. Sus seis acciones solo se sirven a una sesión conectada a GitLab.com con Premium o Ultimate, y todas leen: `orbit.status` comprueba el servicio, `orbit.schema` describe el grafo, `orbit.dsl` sirve el lenguaje de consulta, `orbit.query` ejecuta una consulta, `orbit.tools` lista las herramientas MCP propias de Orbit y `orbit.graph_status` informa de la indexación de un espacio de nombres o de un proyecto. GitLab responde 404 mientras su feature flag `knowledge_graph` está desactivado para quien llama. La [página de Orbit](/gitlab-mcp-server/es/tools/orbit/) explica el flujo de trabajo.

## Preguntas de ejemplo

- "¿Está disponible Orbit para este token de GitLab.com?"
- "Muestra el esquema del grafo de conocimiento"
- "¿Ha terminado de indexarse gitlab-org/gitlab?"

## Cómo llamarlo

- **Dinámica**, la superficie predeterminada: llama a `gitlab_execute_action` con `action` igual al ID de la acción, como `orbit.dsl`, y sus parámetros en `params`. `gitlab_find_action` encuentra un ID a partir de una descripción de la tarea.
- **Meta** (`GITLAB_MCP_TOOL_SURFACE=meta`): llama a `gitlab_orbit` con `action` igual al nombre de la acción, como `dsl`, y sus parámetros en `params`.
- **Individual** (`GITLAB_MCP_TOOL_SURFACE=individual`): llama a la herramienta propia de la acción, como `gitlab_orbit_dsl`, pasándole directamente sus parámetros.

## Disponibilidad

Cuántas de estas acciones sirve una instancia en cada nivel, de un total de 6:

- **Free**: 0
- **Premium**: 0 en una instancia autogestionada, 6 en GitLab.com
- **Ultimate**: 0 en una instancia autogestionada, 6 en GitLab.com

Acciones de solo lectura: 6 de 6, las que conserva un despliegue en modo de solo lectura. A un token con `read_api` y sin `api` se le sirven 6 de las 6.

### `orbit.dsl`

> Read the GitLab Orbit (Knowledge Graph) query language GitLab.com compiles queries in, GQL, as Orbit's query command describes it: its grammar and the JSON Schema of its input, or the same as compact text.

- **Meta-herramienta**: `gitlab_orbit`, acción `dsl`
- **Herramienta individual**: `gitlab_orbit_dsl`
- **Nivel**: Premium, solo GitLab.com
- **Token clásico u OAuth**: `read_api` (o `api`)
- **Token de grano fino**: Orbit: Read en usuario ([página de permisos](/gitlab-mcp-server/es/reference/fine-grained-permissions/#orbit))
- **Comportamiento**: solo lectura, idempotente

| Parámetro         | Tipo     | Requerido | Descripción                                                           |
| ----------------- | -------- | --------- | --------------------------------------------------------------------- |
| `response_format` | `string` | no        | Response format: raw or llm (json is read as raw). When omitted, raw. |

### `orbit.graph_status`

> Inspect GitLab Orbit (Knowledge Graph) indexing status for one group or project, by namespace_id, project_id or full_path: whether Orbit is on, the indexing state of each area, the project counts and the indexed items of each domain, and for a top-level group its Orbit access and trial, which decide whether GitLab.com serves the index at all.

- **Meta-herramienta**: `gitlab_orbit`, acción `graph_status`
- **Herramienta individual**: `gitlab_orbit_graph_status`
- **Nivel**: Premium, solo GitLab.com
- **Token clásico u OAuth**: `read_api` (o `api`)
- **Token de grano fino**: una de: Group: Read en grupo; Orbit: Read en usuario **o** Project: Read en proyecto; Orbit: Read en usuario **o** Group: Read en grupo; Orbit: Read en usuario; Project: Read en proyecto ([página de permisos](/gitlab-mcp-server/es/reference/fine-grained-permissions/#orbit))
- **Comportamiento**: solo lectura, idempotente

| Parámetro         | Tipo      | Requerido | Descripción                                                                                                                                                |
| ----------------- | --------- | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `full_path`       | `string`  | no        | Full path of a group or project to inspect, for example gitlab-org/gitlab. Set exactly one scope field.                                                    |
| `namespace_id`    | `integer` | no        | Group ID to inspect. Set exactly one of namespace_id, project_id, or full_path.                                                                            |
| `project_id`      | `integer` | no        | Project ID to inspect. Set exactly one of namespace_id, project_id, or full_path.                                                                          |
| `response_format` | `string`  | no        | Accepted for compatibility: raw, llm or json. GitLab answers this through GraphQL, which has one structured shape, so every value returns the same output. |

### `orbit.query`

> Execute a read-only GitLab Orbit (Knowledge Graph) query in GQL, the language orbit.dsl describes, naming what orbit.schema lists. A query is one MATCH ... RETURN statement sent as text, with at least one node bounded by its id or a literal property, and a refused query is corrected from the message GitLab answers with.

- **Meta-herramienta**: `gitlab_orbit`, acción `query`
- **Herramienta individual**: `gitlab_orbit_query`
- **Nivel**: Premium, solo GitLab.com
- **Token clásico u OAuth**: `read_api` (o `api`)
- **Token de grano fino**: Orbit: Read en usuario ([página de permisos](/gitlab-mcp-server/es/reference/fine-grained-permissions/#orbit))
- **Comportamiento**: solo lectura, idempotente

| Parámetro         | Tipo     | Requerido | Descripción                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ----------------- | -------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `query`           | `string` | sí        | Orbit query as GQL text, the read-only openCypher 9 based language GitLab.com compiles (orbit.dsl describes it). One statement: MATCH pattern \[WHERE predicates\] RETURN projections \[ORDER BY key \[ASC or DESC\]\] \[SKIP n\] \[LIMIT n\]. Label every node and anchor at least one by its id or a literal property, as in MATCH (p:Project \{full_path: 'gitlab-org/gitlab'\}) RETURN p.id, p.full_path LIMIT 1; LIMIT is not a filter. A relationship type follows a colon, -\[:IN_PROJECT\]-\>, several types are joined by \|, -\[:IN_PROJECT\|CONTAINS\*1..3\]-\>, and a repeat is bounded, \*1..3 at most. A shortest path, MATCH path = ANY SHORTEST (a)-\[:IN_PROJECT\*1..3\]-\>(b) RETURN path, bounds both ends and names its relationship types: GitLab.com refuses the wildcard -\[\*1..3\]-\> there. WHERE takes AND and NOT, never OR. count, sum, avg, min and max aggregate, and every other RETURN item groups; alias an aggregate and sort by the alias: RETURN p, count(mr) AS mr_count ORDER BY mr_count DESC. SKIP takes 0 to 10000 and LIMIT 1 to 1000. orbit.schema lists the entities, properties and relationship types a query names. The JSON query DSL GitLab.com read before is gone. GitLab refuses a query it cannot compile with a message naming the fault. |
| `response_format` | `string` | no        | Response format: raw (structured JSON, the default here), llm (compact text) or gql (the result as a graph pattern table). json is read as raw.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |

### `orbit.schema`

> Inspect the GitLab Orbit (Knowledge Graph) schema: domains, node kinds and edge kinds, with the properties of the node kinds named in expand, or the schema as compact text.

- **Meta-herramienta**: `gitlab_orbit`, acción `schema`
- **Herramienta individual**: `gitlab_orbit_schema`
- **Nivel**: Premium, solo GitLab.com
- **Token clásico u OAuth**: `read_api` (o `api`)
- **Token de grano fino**: una de: Orbit: Read en usuario **o** ningún permiso ([página de permisos](/gitlab-mcp-server/es/reference/fine-grained-permissions/#orbit))
- **Comportamiento**: solo lectura, idempotente

| Parámetro         | Tipo       | Requerido | Descripción                                                                                                                   |
| ----------------- | ---------- | --------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `expand`          | `string[]` | no        | Node names whose properties to include, for example Project or MergeRequest. Without it, nodes are listed without properties. |
| `format`          | `string`   | no        | Schema response format: raw (structured, the default) or llm (compact text; json is read as raw).                             |
| `response_format` | `string`   | no        | Alias for format. Must match format when both are set.                                                                        |

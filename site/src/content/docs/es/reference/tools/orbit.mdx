Orbit es el grafo de conocimiento experimental de GitLab.com sobre el código y los datos de los proyectos. Sus seis acciones solo se sirven a una sesión conectada a GitLab.com con Premium o Ultimate, y todas leen: `orbit.status` comprueba el servicio, `orbit.schema` describe el grafo, `orbit.dsl` sirve el lenguaje de consulta, `orbit.query` ejecuta una consulta, `orbit.tools` lista las herramientas MCP propias de Orbit y `orbit.graph_status` informa de la indexación de un espacio de nombres o de un proyecto. GitLab responde 404 mientras su feature flag `knowledge_graph` está desactivado para quien llama. La [página de Orbit](/gitlab-mcp-server/tools/orbit/) explica el flujo de trabajo.

## Preguntas de ejemplo

- "¿Está disponible Orbit para este token de GitLab.com?"
- "Muestra el esquema del grafo de conocimiento"
- "¿Ha terminado de indexarse gitlab-org/gitlab?"

## Cómo llamarlo

- **Dinámica**, la superficie predeterminada: llama a `gitlab_execute_action` con `action` igual al ID de la acción, como `orbit.dsl`, y sus parámetros en `params`. `gitlab_find_action` encuentra un ID a partir de una descripción de la tarea.
- **Meta** (`GITLAB_MCP_TOOL_SURFACE=meta`): llama a `gitlab_orbit` con `action` igual al nombre de la acción, como `dsl`, y sus parámetros en `params`.
- **Individual** (`GITLAB_MCP_TOOL_SURFACE=individual`): llama a la herramienta propia de la acción, como `gitlab_orbit_dsl`, pasándole directamente sus parámetros.

## Disponibilidad

Cuántas de estas acciones sirve una instancia en cada nivel, de un total de 6:

- **Free**: 0
- **Premium**: 0 en una instancia autogestionada, 6 en GitLab.com
- **Ultimate**: 0 en una instancia autogestionada, 6 en GitLab.com

Acciones de solo lectura: 6 de 6, las que conserva un despliegue en modo de solo lectura.

### `orbit.dsl`

> Retrieve the GitLab Orbit (Knowledge Graph) query DSL schema or LLM grammar.

- **Meta-herramienta**: `gitlab_orbit`, acción `dsl`
- **Herramienta individual**: `gitlab_orbit_dsl`
- **Nivel**: Premium, solo GitLab.com
- **Comportamiento**: solo lectura, idempotente

| Parámetro         | Tipo     | Requerido | Descripción                                                                                        |
| ----------------- | -------- | --------- | -------------------------------------------------------------------------------------------------- |
| `response_format` | `string` | no        | Response format: raw or llm (json is read as raw). When omitted, the GitLab default (raw) applies. |

### `orbit.graph_status`

> Inspect GitLab Orbit (Knowledge Graph) indexing status for one namespace, project, or full_path.

- **Meta-herramienta**: `gitlab_orbit`, acción `graph_status`
- **Herramienta individual**: `gitlab_orbit_graph_status`
- **Nivel**: Premium, solo GitLab.com
- **Comportamiento**: solo lectura, idempotente

| Parámetro         | Tipo      | Requerido | Descripción                                                                                             |
| ----------------- | --------- | --------- | ------------------------------------------------------------------------------------------------------- |
| `full_path`       | `string`  | no        | Full path of a group or project to inspect, for example gitlab-org/gitlab. Set exactly one scope field. |
| `namespace_id`    | `integer` | no        | Namespace/group ID to inspect. Set exactly one of namespace_id, project_id, or full_path.               |
| `project_id`      | `integer` | no        | Project ID to inspect. Set exactly one of namespace_id, project_id, or full_path.                       |
| `response_format` | `string`  | no        | Response format: raw or llm (json is read as raw). When omitted, the GitLab default (raw) applies.      |

### `orbit.query`

> Execute a read-only GitLab Orbit (Knowledge Graph) query in the version 12 DSL orbit.dsl serves, naming the entities and relationship types orbit.schema lists. Every query has a query_type (traversal, aggregation, neighbors, or path_finding) and lists its nodes in a nodes array, and a refused query is corrected from the message GitLab answers with.

- **Meta-herramienta**: `gitlab_orbit`, acción `query`
- **Herramienta individual**: `gitlab_orbit_query`
- **Nivel**: Premium, solo GitLab.com
- **Comportamiento**: solo lectura, idempotente

| Parámetro         | Tipo     | Requerido | Descripción                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ----------------- | -------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `query`           | `object` | sí        | Orbit query in the version 12 DSL that orbit.dsl serves, as a JSON object. Required: query_type (traversal, aggregation, neighbors or path_finding) and nodes, a list of node selectors \{id, entity, columns, filters, node_ids, id_range\} even for one node. A filter is a bare value for equality or an object keyed by operators such as \{"starts_with": "gitlab-org/"\}, never \{op, value\}. A traversal or aggregation query needs node_ids or filters on a node. A neighbors query takes one node and neighbors \{direction, rel_types\}, where direction defaults to outgoing (pass both for every relationship). A path_finding query takes two nodes and path \{type: shortest, from, to, max_depth 1 to 3, rel_types\} with rel_types required (\* for any). Aggregations are \{count: "mr", as: "n"\}, order_by is "node.property" ("-node.property" descending). orbit.schema lists the entities, properties and relationship types. GitLab refuses a query it cannot compile with a message naming the fault. |
| `response_format` | `string` | no        | Response format: raw or llm (json is read as raw). When omitted, the GitLab default (raw) applies.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |

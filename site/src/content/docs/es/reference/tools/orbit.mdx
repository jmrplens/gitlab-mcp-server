Orbit es el grafo de conocimiento experimental de GitLab.com sobre el código y los datos de los proyectos. Sus quince acciones solo se sirven a una sesión conectada a GitLab.com con Premium o Ultimate, y todas leen: `orbit.status` comprueba el servicio, `orbit.schema` describe el grafo, `orbit.dsl` sirve el lenguaje de consulta, `orbit.query` ejecuta una consulta y `orbit.named_query` una de las consultas con nombre de GitLab, `orbit.grep` busca en un grupo o proyecto, `orbit.context` resuelve una referencia a su resumen, `orbit.graph_status` informa de la indexación de un espacio de nombres o de un proyecto, y `orbit.tools`, `orbit.command_list`, `orbit.response_format`, `orbit.query_templates` y las tres lecturas de skills describen lo que sirve Orbit. GitLab.com solo sirve el índice de un grupo y sus consultas bajo el acceso a Orbit del grupo de nivel superior. La [página de Orbit](/gitlab-mcp-server/es/tools/orbit/) explica el flujo de trabajo.

## Preguntas de ejemplo

- "¿Está disponible Orbit para este token de GitLab.com?"
- "Muestra el esquema del grafo de conocimiento"
- "¿Ha terminado de indexarse gitlab-org/gitlab?"
- "Busca en gitlab-org/gitlab los merge requests sobre límites de peticiones"
- "Resume este merge request con sus archivos cambiados y sus jobs fallidos"
- "Ejecuta la plantilla de consulta recent_merges"

## Cómo llamarlo

- **Dinámica**, la superficie predeterminada: llama a `gitlab_execute_action` con `action` igual al ID de la acción, como `orbit.command_list`, y sus parámetros en `params`. `gitlab_find_action` encuentra un ID a partir de una descripción de la tarea.
- **Meta** (`GITLAB_MCP_TOOL_SURFACE=meta`): llama a `gitlab_orbit` con `action` igual al nombre de la acción, como `command_list`, y sus parámetros en `params`.
- **Individual** (`GITLAB_MCP_TOOL_SURFACE=individual`): llama a la herramienta propia de la acción, como `gitlab_orbit_command_list`, pasándole directamente sus parámetros.

## Disponibilidad

Cuántas de estas acciones sirve una instancia en cada nivel, de un total de 15:

- **Free**: 0
- **Premium**: 0 en una instancia autogestionada, 15 en GitLab.com
- **Ultimate**: 0 en una instancia autogestionada, 15 en GitLab.com

Acciones de solo lectura: 15 de 15, las que conserva un despliegue en modo de solo lectura. A un token con `read_api` y sin `api` se le sirven 15 de las 15.

### `orbit.command_list`

> List the commands GitLab's Orbit (Knowledge Graph) MCP endpoint runs, with the description and input schema of each and the action of this server that runs it: query_graph is orbit.query, get_graph_schema is orbit.schema and get_response_format is orbit.response_format.

- **Meta-herramienta**: `gitlab_orbit`, acción `command_list`
- **Herramienta individual**: `gitlab_orbit_command_list`
- **Nivel**: Premium, solo GitLab.com
- **Token clásico u OAuth**: `read_api` (o `api`)
- **Token de grano fino**: Orbit: Read en usuario ([página de permisos](/gitlab-mcp-server/es/reference/fine-grained-permissions/#orbit))
- **Comportamiento**: solo lectura, idempotente

| Parámetro         | Tipo       | Requerido | Descripción                                                                                                                  |
| ----------------- | ---------- | --------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `command_names`   | `string[]` | no        | Names of the Orbit commands to describe (query_graph, get_graph_schema, get_response_format). Empty describes every command. |
| `response_format` | `string`   | no        | Response format: raw or llm (json is read as raw). When omitted, raw.                                                        |

### `orbit.context`

> Resolve one reference to a work item, merge request, job, pipeline, branch or commit through GitLab Orbit (Knowledge Graph) and read its summary, discussions, changed files and failed jobs' logs, and with expand the graph neighborhood of one of the first three, one billable query. A reference it cannot resolve is found false with the reason, not_found also for an object the user or token may not read: a fine-grained token needs, beside read_orbit, permission to read on the object's own project or group. Summary parts it may not read are left out, and a failed expansion carries its reason.

- **Meta-herramienta**: `gitlab_orbit`, acción `context`
- **Herramienta individual**: `gitlab_orbit_context`
- **Nivel**: Premium, solo GitLab.com
- **Token clásico u OAuth**: `read_api` (o `api`)
- **Token de grano fino**: Orbit: Read en usuario ([página de permisos](/gitlab-mcp-server/es/reference/fine-grained-permissions/#orbit))
- **Comportamiento**: solo lectura, idempotente

| Parámetro         | Tipo       | Requerido | Descripción                                                                                                                                                                                                                                                                                    |
| ----------------- | ---------- | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `tokens`          | `string[]` | sí        | Exactly one reference to a GitLab object: Type\[id\] (WorkItem\[1\], Job\[2\]), a GID, an instance URL, path!iid (merge request), path\#iid (work item), path&iid (epic) or path@ref (branch or commit). orbit.grep returns the token of a work item, merge request, commit or branch it finds |
| `expand`          | `boolean`  | no        | Attach the graph neighborhood of a work item, merge request or job, which GitLab reads with one graph query billed like orbit.query; false reads the summary alone                                                                                                                             |

### `orbit.grep`

> Search what one group or project holds through GitLab Orbit (Knowledge Graph): work items, merge requests, code, commits, notes, milestones, users, projects, groups and branches, by namespace_id, project_id or full_path. Every hit but a file carries its token, which orbit.context reads for a work item, merge request, commit or branch, a note also the token of what it is on, and most carry the id orbit.query filters on.

- **Meta-herramienta**: `gitlab_orbit`, acción `grep`
- **Herramienta individual**: `gitlab_orbit_grep`
- **Nivel**: Premium, solo GitLab.com
- **Token clásico u OAuth**: `read_api` (o `api`)
- **Token de grano fino**: Orbit: Read, Global Search: Use en usuario ([página de permisos](/gitlab-mcp-server/es/reference/fine-grained-permissions/#orbit))
- **Comportamiento**: solo lectura, idempotente

| Parámetro         | Tipo       | Requerido | Descripción                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ----------------- | ---------- | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `search`          | `string`   | sí        | What to search for, 2 to 256 bytes once trimmed                                                                                                                                                                                                                                                                                                                                                                                    |
| `full_path`       | `string`   | no        | Full path of the group or project to search. Give exactly one of namespace_id, project_id and full_path                                                                                                                                                                                                                                                                                                                            |
| `limit`           | `integer`  | no        | Most results to answer, 1 to 50. GitLab answers 20 when omitted                                                                                                                                                                                                                                                                                                                                                                    |
| `namespace_id`    | `integer`  | no        | ID of the group to search. Give exactly one of namespace_id, project_id and full_path                                                                                                                                                                                                                                                                                                                                              |
| `per_scope`       | `integer`  | no        | Most results of one scope, 1 to 10 and never above limit. When omitted, 5, or limit when that is lower                                                                                                                                                                                                                                                                                                                             |
| `project_id`      | `integer`  | no        | ID of the project to search. Give exactly one of namespace_id, project_id and full_path                                                                                                                                                                                                                                                                                                                                            |
| `response_format` | `string`   | no        | Response format: raw (structured JSON, the default) or llm (compact text). json is read as raw.                                                                                                                                                                                                                                                                                                                                    |
| `scopes`          | `string[]` | no        | What to search: work_items, merge_requests, blobs, commits, notes, milestones, users, projects, groups, branches, an alias (mr, issue, code, comment, branch) or a node name (MergeRequest, File). ### `orbit.query`

> Execute a read-only GitLab Orbit (Knowledge Graph) query in GQL, the language orbit.dsl describes, naming what orbit.schema lists. A query is one MATCH ... RETURN statement sent as text, with at least one node bounded by its id or a literal property, and a refused query is corrected from the message GitLab answers with.

- **Meta-herramienta**: `gitlab_orbit`, acción `query`
- **Herramienta individual**: `gitlab_orbit_query`
- **Nivel**: Premium, solo GitLab.com
- **Token clásico u OAuth**: `read_api` (o `api`)
- **Token de grano fino**: Orbit: Read en usuario ([página de permisos](/gitlab-mcp-server/es/reference/fine-grained-permissions/#orbit))
- **Comportamiento**: solo lectura, idempotente

| Parámetro         | Tipo     | Requerido | Descripción                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ----------------- | -------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `query`           | `string` | sí        | Orbit query as GQL text, the read-only openCypher 9 based language GitLab.com compiles (orbit.dsl describes it). One statement: MATCH pattern \[WHERE predicates\] RETURN projections \[ORDER BY key \[ASC or DESC\]\] \[SKIP n\] \[LIMIT n\]. Label every node and anchor at least one by its id or a literal property, as in MATCH (p:Project \{full_path: 'gitlab-org/gitlab'\}) RETURN p.id, p.full_path LIMIT 1; LIMIT is not a filter. A relationship type follows a colon, -\[:IN_PROJECT\]-\>, several types are joined by \|, -\[:IN_PROJECT\|CONTAINS\*1..3\]-\>, and a repeat is bounded, \*1..3 at most. A shortest path, MATCH path = ANY SHORTEST (mr:MergeRequest \{id: 1\})-\[:IN_PROJECT\*1..3\]-\>(p:Project \{id: 2\}) RETURN path, labels and anchors both ends and names its relationship types: GitLab.com refuses the wildcard -\[\*1..3\]-\> there. WHERE takes AND and NOT, never OR. count, sum, avg, min and max aggregate, and every other RETURN item groups; alias an aggregate and sort by the alias: RETURN p, count(mr) AS mr_count ORDER BY mr_count DESC. SKIP takes 0 to 10000 and LIMIT 1 to 1000. orbit.schema lists the entities, properties and relationship types a query names. The JSON query DSL GitLab.com read before is gone. GitLab refuses a query it cannot compile with a message naming the fault. |
| `response_format` | `string` | no        | Response format: raw (structured JSON, the default here), llm (compact text) or gql (the result as a graph pattern table). json is read as raw.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |

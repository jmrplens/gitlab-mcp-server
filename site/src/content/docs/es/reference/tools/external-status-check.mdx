Una comprobación de estado externa envía los merge requests de un proyecto a un servicio externo, que responde con un estado de aprobado o fallido que puede condicionar el merge. Estas acciones gestionan las comprobaciones de un proyecto (listar, crear, actualizar, borrar), listan el estado de cada comprobación en un merge request, fijan ese estado y reintentan una comprobación que falló.

## Preguntas de ejemplo

- "¿Qué comprobaciones de estado externas tiene el proyecto 42?"
- "Muestra las comprobaciones de estado del merge request !15"
- "Reintenta la comprobación de cumplimiento fallida del merge request !15"

## Cómo llamarlo

- **Dinámica**, la superficie predeterminada: llama a `gitlab_execute_action` con `action` igual al ID de la acción, como `external_status_check.create_project`, y sus parámetros en `params`. `gitlab_find_action` encuentra un ID a partir de una descripción de la tarea.
- **Meta** (`GITLAB_MCP_TOOL_SURFACE=meta`): llama a `gitlab_external_status_check` con `action` igual al nombre de la acción, como `create_project`, y sus parámetros en `params`.
- **Individual** (`GITLAB_MCP_TOOL_SURFACE=individual`): llama a la herramienta propia de la acción, como `gitlab_create_project_external_status_check`, pasándole directamente sus parámetros.

## Disponibilidad

Cuántas de estas acciones sirve una instancia en cada nivel, de un total de 8:

- **Free**: 0
- **Premium**: 0
- **Ultimate**: 8

Acciones de solo lectura: 3 de 8, las que conserva un despliegue en modo de solo lectura. A un token con `read_api` y sin `api` se le sirven 3 de las 8.

### `external_status_check.create_project`

> Create an external status check service for a project. Returns: the created check with id, name, external_url, hmac, and protected branches. See also: [`external_status_check.list_project`](#external_status_checklist_project), [`external_status_check.update_project`](#external_status_checkupdate_project), [`external_status_check.delete_project`](#external_status_checkdelete_project).

- **Meta-herramienta**: `gitlab_external_status_check`, acción `create_project`
- **Herramienta individual**: `gitlab_create_project_external_status_check`
- **Nivel**: Ultimate
- **Token clásico u OAuth**: `api`
- **Token de grano fino**: External Status Check Service: Create en proyecto ([página de permisos](/gitlab-mcp-server/reference/fine-grained-permissions/#external_status_check))
- **Comportamiento**: escribe, no idempotente

| Parámetro              | Tipo             | Requerido | Descripción                                     |
| ---------------------- | ---------------- | --------- | ----------------------------------------------- |
| `external_url`         | `string`         | sí        | External URL for the status check               |
| `name`                 | `string`         | sí        | Name of the external status check               |
| `project_id`           | `string/integer` | sí        | Project ID or URL-encoded path                  |
| `protected_branch_ids` | `integer[]`      | no        | IDs of protected branches to scope the check to |
| `shared_secret`        | `string`         | no        | Shared secret for HMAC verification             |

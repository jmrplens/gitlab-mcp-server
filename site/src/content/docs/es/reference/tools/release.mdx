Una release envuelve un tag con sus notas, hitos y recursos descargables. Estas acciones listan releases, leen una o la última, crean una (para un tag existente o uno nuevo a partir de una referencia), actualizan y borran una, y gestionan los enlaces de recursos de una release, uno a uno o en lote tras una compilación. Borrar una release conserva su tag.

## Preguntas de ejemplo

- "Lista las releases del proyecto 42"
- "Crea la release v2.0.0 con el changelog como notas"
- "Adjunta los artefactos de la compilación a la release v2.0.0"

## Cómo llamarlo

- **Dinámica**, la superficie predeterminada: llama a `gitlab_execute_action` con `action` igual al ID de la acción, como `release.create`, y sus parámetros en `params`. `gitlab_find_action` encuentra un ID a partir de una descripción de la tarea.
- **Meta** (`GITLAB_MCP_TOOL_SURFACE=meta`): llama a `gitlab_release` con `action` igual al nombre de la acción, como `create`, y sus parámetros en `params`.
- **Individual** (`GITLAB_MCP_TOOL_SURFACE=individual`): llama a la herramienta propia de la acción, como `gitlab_release_create`, pasándole directamente sus parámetros.

## Disponibilidad

Todos los niveles sirven el grupo completo, tanto en instancias autogestionadas como en GitLab.com.

Acciones de solo lectura: 5 de 12, las que conserva un despliegue en modo de solo lectura.

### `release.create`

> Create a release for a tag, optionally creating the tag from a ref and attaching asset links. Returns: the created release with author, commit, assets, milestones, and _links. See also: [`release.update`](#releaseupdate), [`release.link_create`](#releaselink_create), [`tag.create`](/gitlab-mcp-server/reference/tools/tag/#tagcreate).

- **Meta-herramienta**: `gitlab_release`, acción `create`
- **Herramienta individual**: `gitlab_release_create`
- **Nivel**: Free
- **Comportamiento**: escribe, no idempotente

| Parámetro     | Tipo             | Requerido | Descripción                                                                                                          |
| ------------- | ---------------- | --------- | -------------------------------------------------------------------------------------------------------------------- |
| `project_id`  | `string/integer` | sí        | Project ID or URL-encoded path                                                                                       |
| `tag_name`    | `string`         | sí        | Tag name associated with the release                                                                                 |
| `assets`      | `object`         | no        | Asset links to attach to the release at creation time                                                                |
| `description` | `string`         | no        | Release notes (Markdown supported)                                                                                   |
| `milestones`  | `string[]`       | no        | Milestone titles to associate with the release                                                                       |
| `name`        | `string`         | no        | Release title                                                                                                        |
| `ref`         | `string`         | no        | Branch or commit SHA to create tag from when tag_name does not exist. Include this when the prompt says ref/from ref |
| `released_at` | `string`         | no        | Date of the release in ISO 8601 format                                                                               |
| `tag_message` | `string`         | no        | Message to use for the annotated tag (creates annotated tag instead of lightweight)                                  |

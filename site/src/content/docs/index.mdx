faq:
  - q: "What is GitLab MCP Server?"
    a: "GitLab MCP Server is a free, open-source [Model Context Protocol](https://modelcontextprotocol.io/) server that lets AI assistants interact with GitLab through natural language. It exposes the GitLab REST v4 and GraphQL APIs as MCP tools, so an assistant can review merge requests, triage pipelines, manage issues, and draft releases on your behalf. It ships as a single Go binary and runs locally over stdio or remotely over HTTP."
  - q: "Which AI assistants work with GitLab MCP Server?"
    a: "Any MCP-compatible client works — including VS Code with GitHub Copilot, Claude Desktop, Cursor, and Claude Code, plus any other client that speaks the Model Context Protocol over stdio or HTTP transport. Configuration is a small JSON snippet per client."
  - q: "Is GitLab MCP Server free and open source?"
    a: "Yes. GitLab MCP Server is free and open source under the MIT license, with the full source on GitHub. There is no paid tier of the server itself; GitLab Premium or Ultimate features are gated only by your own GitLab instance license, not by the MCP server."
  - q: "Does it work with self-hosted GitLab and Community Edition?"
    a: "Yes. It works with GitLab.com and self-hosted instances, and with both Community Edition and Enterprise Edition. Point it at any GitLab URL with a personal access token. Premium and Ultimate tools register only when the connected instance is licensed for them."
